# 💬 Chatbot template

A simple Streamlit app that shows how to build a chatbot using OpenAI's GPT-3.5.

[![Open in Streamlit](https://mactar221.github.io)](https://mactar221.github.io)

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r https://mactar221.github.io
   ```

2. Run the app

   ```
   $ streamlit run https://mactar221.github.io
   ```
